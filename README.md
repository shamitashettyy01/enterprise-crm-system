# Enterprise CRM System

## 📌 Project Overview
Enterprise CRM System is a professional customer relationship management application designed to manage leads, customers, sales activities, and business operations efficiently.

## 🚀 Features

### 🔐 Authentication
- User Login Page
- Secure Navigation

### 📊 Dashboard
- CRM Overview
- Quick Access to Modules
- Business Insights

### 👥 Customers
- Customer Records
- Customer Management

### 🎯 Leads
- Lead Tracking
- Lead Status Monitoring

### 💰 Sales
- Sales Information
- Performance Monitoring

### 📝 Activities
- Activity Logs
- Task Tracking

### ⚙️ Admin Panel
- Role-Based Management
- Administrative Controls

## 🛠️ Tech Stack

- Next.js
- React.js
- JavaScript
- CSS
- Git & GitHub
